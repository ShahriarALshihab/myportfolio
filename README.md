# 🚀 Shahriar Al Shihab — Personal Portfolio

> A modern, responsive personal portfolio website built with Next.js, Tailwind CSS, and Framer Motion.

🌐 **Live Site:** [https://shahriar-al-shihab.vercel.app](https://shahriar-al-shihab.vercel.app)

---

## ✨ Features

- ⚡ Built with **Next.js** (App Router)
- 🎨 Styled with **Tailwind CSS**
- 🎞️ Smooth animations powered by **Framer Motion**
- 🌓 **Dark / Light** theme toggle
- 📱 Fully **responsive** — mobile, tablet, laptop, desktop
- 💼 Project cards with individual **project detail pages**
- 🧠 Skills section with **tech icons**
- 📬 **Contact form**
- 📄 **Download CV** button
